# Farah & Zeyad Wedding Invitation

A responsive, romantic wedding invitation website for Farah & Zeyad. The original invitation artwork is included unchanged at `images/invitation.png`.

## Upload and publish

This project is ready to upload as-is. Upload the contents of this folder to the root of your GitHub repository, then select **Settings → Pages → Deploy from a branch → main → /(root)**.

Keep the included folder layout intact:

- `index.html`
- `css/style.css`
- `js/script.js`
- `images/invitation.png`

## RSVP is already connected

The invitation embeds the published Farah & Zeyad Google RSVP form. Guests enter their name and select Yes or No inside the form. Google Forms shows its own confirmation and validation messages, and records replies with timestamps in the linked response spreadsheet. No endpoint or field IDs need to be added to these files.

- RSVP form: https://docs.google.com/forms/d/e/1FAIpQLSfVDw4yjfwD_ECI07mlk-cRV9E_KUNHyINzoqseQbMbUEGVQg/viewform
- The response spreadsheet is linked to the form in the Google account that owns it. Keep that spreadsheet private; do not add its link to the public website or repository.
